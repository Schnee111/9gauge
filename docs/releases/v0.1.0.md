# 9Gauge v0.1.0 Release Notes

**Release Date:** September 2026  
**Build Target:** macOS (Universal), Windows (x64), Linux (x86_64 AppImage / deb)

---

## Highlights

### AETER Frosted Glass HUD
- Utilitarian premium glassmorphism popover (`360px` width) with dark substrate opacity, crisp specular double-bezel, and zero sci-fi slop.
- Non-activating popover architecture: click tray icon to inspect real-time metrics without losing keyboard focus in VSCode or terminal.
- Enforced tabular figures (`font-feature-settings: "tnum"`) using JetBrains Mono across all metrics and timestamps.

### Dynamic Multi-Provider Telemetry
- Data-driven upstream card list parsing 9Router `byProvider` map dynamically (Google Antigravity, Qoder, and custom OpenAI-compatible endpoints).
- Live token burn velocity tracking (`tok/h` and `req/m`) derived from server throughput buckets.
- Micro-feed displaying real-time requests with latency, token consumption, and status code.

### Robust Fail-Open Headless Engine (`gauge-core`)
- Server-Sent Events (SSE) telemetry stream ingestion with 35-second heartbeat watchdog and auto-reconnect exponential backoff (1s–30s).
- Full REST fallback poller for degraded connectivity.
- ADR-0003 multi-strategy authentication: Local CLI SHA-256 token derivation (`x-9r-cli-token`) and remote dashboard session JWT with throttled re-login.
- Lock-free `ArcSwap` state hub for zero-contention UI reads.
